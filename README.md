# PCC Explorer 標案每日快報系統

專業的政府標案監控與機關代碼適配系統。透過自動化腳本每日同步官方名冊與最新標案資料。

## 📊 系統狀態 (System Status)
*   **最新標案日期**：20260424
*   **官方機關名冊日期**：20260302
*   **系統最後運行時間**：20260425

## 🚀 核心功能
*   **每日快報**：自動抓取 PCC 最新公開招標資料。
*   **智慧對照**：將官方 ID 轉換為標案點狀格式 (如 A.19.05.01)。
*   **雙軌字典**：區分「有效機關」與「歷史機關」，確保搜尋無死角。
*   **全自動維護**：利用 GitHub Actions 達成 24/7 無人值守同步。

## 📁 目錄結構
*   `pcc_crawler.py`：主進程 (標案抓取)。
*   `index.html`：視覺化看板。
*   `orglist/`：機關字典管理模組（包含同步與清洗工具）。
