# PCC Agency Dictionary System (PADS)

本資料夾負責管理並維護政府標案系統的機關代碼對照表。

## 0. 系統狀態
*   最新資料時間：20260424
*   最新檢查時間：20260302

## 1. 資料來源 (Data Source)
*   **官方來源**：[行政院人事行政總處 - 機關代碼資料集](https://data.gov.tw/dataset/7307)
*   **自動下載連結**：`https://www.dgpa.gov.tw/open/code/orglist.csv`

## 2. 代碼轉換規則 (ID Transformation)
為了與標案系統 (PCC) 對接，本系統將官方 10 碼（含末位英碼）轉換為「點狀精簡格式」：
*   **拆分規則**：1(首位) - 2 - 2 - 2 - 2 (例如 `A 19 05 01 00 Q`)
*   **處理邏輯**：
    1. 移除末尾連續的 `00` 段落。
    2. 移除子段落（第 2 段之後）的前導零 `0`。
*   **範例**：
    *   `310350000Q` -> `3.10.35`
    *   `A19050100G` -> `A.19.5.1`
    *   `A47010000C` -> `A.47.1`

## 3. 資料結構 (Data Structure)
字典分為兩個 JSON 檔案：
*   `units_Active.json`：目前有效的機關。
*   `units_History.json`：已裁撤或改組的歷史機關。

### JSON 欄位規格：
```json
"A.19.5.1": {
  "招標機關代碼": "A.19.5.1",
  "機關代碼": "A19050100G",
  "機關名稱": "農業部農村發展及水土保持署臺北分署",
  "郵遞區號": "231069",
  "縣市": "新北市",
  "主管代碼": "A19050000G",
  "主管名稱": "農業部農村發展及水土保持署"
}
```

## 4. 維護工具 (Maintainer)
*   執行 `python clean_dictionary.py` 會自動連線官網，偵測官方最後更新日期（Last-Modified），下載並重新產出上述字典檔。
